# Converse Shop — учебный интернет-магазин

## Постановка контрольной работы №1

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

В рамках контрольной работы необходимо разработать многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

Проект должен включать:

- главную страницу;
- страницу каталога;
- страницу карточки товара или услуги;
- страницу оформления заявки;
- страницу контактов;
- семантическую HTML-разметку;
- внешний CSS-файл;
- базовую навигацию;
- оформление основных блоков страницы.

## История выполнения

- Практическая работа 1: создан Git-репозиторий, опубликован проект на GitHub Pages.
- Практическая работа 2: создан HTML-каркас стартовой страницы и выполнено базовое CSS-оформление.
- Практическая работа 3: добавлена форма заявки, модальное окно и базовая валидация.
- Практическая работа 4: добавлены CSS-переменные, состояния интерфейса и упорядочена структура стилей.
- Практическая работа 5: создана многостраничная структура сайта, добавлены единая навигация и якорные ссылки.
- Практическая работа 6: добавлены Flexbox-навигация и Grid-раскладка карточек и каталога.
- Практическая работа 7: выполнен рефакторинг CSS-стилей по методологии БЭМ.
- Практическая работа 8: добавлены страницы `product.html` и `order.html`, таблица характеристик, форма заявки, бейдж товара через `position: absolute`, кнопка «Наверх» через `position: fixed`, sticky-шапка через `position: sticky`.

## Реализованные элементы интерфейса

- кнопки «Быстрый заказ» в карточках товаров;
- модальное окно с формой заявки (имя, e-mail);
- отдельная страница оформления заявки с полной формой (имя, e-mail, телефон, товар, комментарий, согласие);
- базовая HTML-валидация;
- базовая JS-обработка формы;
- сообщение об успешной отправке;
- таблица характеристик товара;
- бейдж «Хит» на карточке товара;
- кнопка «Наверх» (position: fixed);
- sticky-шапка (position: sticky).

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- позиционирование: `relative`, `absolute`, `sticky`, `fixed`, `z-index`.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — карточка товара с таблицей характеристик;
- `order.html` — страница оформления заявки;
- `contacts.html` — контактная информация;
- `css/index.css` — стили главной страницы;
- `css/catalog.css` — стили страницы каталога;
- `css/product.css` — стили карточки товара;
- `css/order.css` — стили страницы оформления заявки;
- `css/contacts.css` — стили страницы контактов;
- `js/main.js` — скрипт модального окна и валидации;
- `img/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- Flexbox для блока преимуществ (текст + фото);
- CSS Grid для сетки карточек на главной и в каталоге;
- CSS Grid для страницы каталога с фильтрами и списком товаров;
- CSS Grid для карточки товара (фото + информация).

## Позиционирование

В проекте используются все четыре типа позиционирования:

- `position: relative` — контейнер изображения в карточке товара;
- `position: absolute` — бейдж «Хит» на изображении товара;
- `position: sticky` — шапка сайта;
- `position: fixed` — кнопка «Наверх»;
- `z-index` — у шапки и кнопки «Наверх».

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `product-detail` — карточка товара на отдельной странице;
- `product-table` — таблица характеристик;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `back-to-top` — кнопка «Наверх»;
- `section--card` — белая карточка для контента;
- `section--advantages` — блок преимуществ.

## Как проверить проект

1. Открыть `index.html` в браузере.
2. Проверить переходы между страницами через меню.
3. Проверить работу якорных ссылок «Преимущества» и «Популярные товары».
4. Проверить модальное окно: клик на «Быстрый заказ».
5. Открыть `catalog.html`, проверить фильтры и карточки.
6. Кликнуть «Подробнее» — откроется `product.html`.
7. На `product.html` проверить таблицу характеристик и бейдж.
8. Кликнуть «Оформить заявку» — откроется `order.html`.
9. На `order.html` заполнить форму и проверить валидацию.
10. Открыть `contacts.html`, проверить контакты.
